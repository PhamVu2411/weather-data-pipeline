# Weather Data Pipeline

- **Nguồn dữ liệu:** Open-Meteo API , https://open-meteo.com
- **Mục tiêu:** Project theo dây chuyền tự động lấy dữ liệu thời tiết hằng ngày, lưu lại, làm sạch, rồi vẽ biểu đồ để xem tình hình ví dụ như thống kê ngày mưa, nhiệt độ trung bình, so sánh với các năm trước, .....
